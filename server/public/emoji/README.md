# 内置公共表情包目录

服务端启动时会扫描本目录，把这里的图片作为 **公共表情包**（`isPublic=true`）写入数据库，
所有已登录用户都能看到并使用它们。

## 目录约定

```
public/emoji/
├── 经典表情/            <- 一级子目录名 = 表情包名称
│   ├── 大笑.png         <- 文件名（去扩展名）= 表情名称
│   └── 哭泣.gif
└── pets/
    └── cat.webp
```

- **一级子目录**：每个子目录是一个公共表情包，目录名直接作为包名（支持中文）
- **图片文件**：支持 `jpg` / `jpeg` / `png` / `gif` / `webp`
- **表情名称**：取文件名去掉扩展名
- 可自由增删图片与目录，**下次启动自动同步**
- 空目录会被忽略；不含合法图片的目录不会建包

## 校验规则

图片会按 **magic bytes**（文件头）校验，而不是按扩展名：

| 格式 | 文件头 |
| --- | --- |
| JPEG | `FF D8 FF` |
| PNG | `89 50 4E 47 0D 0A 1A 0A` |
| GIF | `GIF87a` / `GIF89a` |
| WEBP | `RIFF....WEBP` |

- 扩展名像图片但内容不是图片的文件（例如把文本改名成 `.png`）会被**跳过并记录警告**
- 单张超过 1MB 的文件会被跳过
- 非图片扩展名的文件（如 `.txt`）直接忽略

## 行为说明

- 公共表情包**不可删除、不可上传**（接口返回 403）
- 公共表情对所有已登录用户可见；用户自建表情包仍按情侣空间隔离
- 每次启动会**重建**公共包内容，保证与磁盘一致（不会重复累加）
- 公共表情的数据库 id 形如 `e_public<包序号><文件序号>`，
  序号由目录名/文件名的排序决定，重启后保持稳定

## 添加一个公共表情包

```bash
cd server/public/emoji
mkdir 我的表情
cp ~/图片/开心.png 我的表情/
# 重启服务即可生效
```

> 提示：表情接口返回的 `url` 为 `/api/emoji/blob/<id>`，客户端仍需带上
> `Authorization` 头或 `?token=<jwt>` 才能获取图片。
