内置公共表情包目录。

目录约定（随插件一起发布，API.md §6 的 isPublic=true 内置公共表情包）：

    public/emoji/<表情包名>/<文件名>.jpg|jpeg|png|gif|webp

说明：
- 每个子目录 = 一个公共表情包，包名就是子目录名（例如 public/emoji/哆啦A梦/）。
- 插件启用后会自动扫描本目录；目录内容指纹变化时重建这些表情包的数据库记录。
- 单个文件上限 1MB，且会按 magic bytes 校验真实格式，非法文件会被跳过。
- 公共表情包（id 形如 p_public_xxx）在 App 里所有人可见，但不可删除、不可上传。
- 用户自建的表情包与这里的目录互不影响。
