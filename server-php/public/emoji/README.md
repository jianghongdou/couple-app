# 内置公共表情包目录

把图片按「一个子目录 = 一个表情包」的方式放在这里，所有用户都能看到（`isPublic: true`、`isSystem: true`）。

```
public/emoji/
├── README.md         本说明文件（不会被扫描）
├── 日常/              目录名就是表情包名称
│   ├── 大笑.png
│   ├── 无语.jpg
│   └── 比心.gif
└── 动物/
    └── 猫猫.webp
```

规则：

- 支持格式：`jpg` / `jpeg` / `png` / `gif` / `webp`；**服务端按文件头（magic bytes）校验**，
  改了扩展名的假图片会被跳过，单张不得超过 1MB。
- 表情 id 由「包序号 + 文件序号」生成（形如 `e_public11`），排序稳定，重启后不会错位。
- 包内容每次都会按磁盘目录重建，因此**删掉文件即等于删掉表情**；
  用户自建包（`p_` 前缀但不含 `p_public_`）完全不受影响。
- 添加/修改文件后执行 `php bin/console.php sync-public-emoji` 立即生效；
  不执行也可以 —— 下一次收到请求时服务端发现目录内容变化会自动同步。
- 公共表情包在后台与客户端都**不可删除、不可上传**（返回 403）。
