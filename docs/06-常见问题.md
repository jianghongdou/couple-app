# 06 · 常见问题

按「遇到的现象」查。

---

## A. 编译相关

**Q：一定要有 Mac 吗？**
不需要。macOS 编译交给 GitHub Actions（免费），本机只要有 Git。见 [02-云编译与安装.md](02-云编译与安装.md)。

**Q：Actions 里没有「构建 iOS IPA」这个工作流？**
确认仓库里存在 `.github/workflows/ios-build.yml` 并且已经推送上去。如果 Actions 页面顶部提示需要启用，点一下确认按钮。

**Q：构建失败怎么办？**
把失败任务的日志最后 60 行复制出来，按 [07-编译失败怎么反馈.md](07-编译失败怎么反馈.md) 的方式反馈。

**Q：能在本机 Windows 上验证代码吗？**
可以跑两件事：
- 服务端：`cd server && npm install && npm test`（真跑一遍接口测试）
- 图标生成：`node tools/make-icon.mjs`
Swift 代码只能在 macOS 上编译。

**Q：构建一次要多久？**
首次 5～8 分钟；macOS runner 高峰期可能排队。

**Q：IPA 下载链接过期了？**
Artifacts 默认保存 90 天。重新跑一次工作流；或者打 tag（`git tag v1.0.0 && git push --tags`）让 IPA 永久挂在 Release 页面。

## B. 安装相关

**Q：IPA 下载后直接装，提示未签名？**
这是**未签名 IPA**，必须用自己的证书签名后才能装。见 [01-签名证书判断.md](01-签名证书判断.md)。

**Q：报错 `The executable was signed with invalid entitlements`？**
完整版里的扩展没法和你的描述文件匹配。**改装轻量版**。

**Q：完整版和轻量版有什么区别？**
只差灵动岛扩展。其余功能完全一样。

**Q：能同时装完整版和轻量版吗？**
可以，它们是两个不同的 App（Bundle ID 不同），但**数据不互通**（记账、密码本各存各的）。

**Q：7 天后 App 打不开了？**
免费 Apple ID 签名的有效期就是 7 天。重新签名**覆盖安装**即可（千万别先删除 App，删了本机数据就没了）。

**Q：升级 App 会不会丢数据？**
同一个 Bundle ID 覆盖安装不会丢。换 Bundle ID（例如从轻量版换完整版）会当作新 App，本机数据不互通 —— 换之前先在「我的 → 数据与隐私 → 导出本机数据」备份。

**Q：手机上提示"未受信任的开发者"？**
设置 → 通用 → VPN与设备管理 → 找到你的证书 → 信任。

## C. 服务器与连接

**Q：服务器还没部署好，App 能先用吗？**
能。登录页最下面有一张「暂时没有服务器？」卡片，点 **本机单机使用**，填个称呼和头像就能进。
单机模式下账本、密码本、宠物、签到、愿望、加班工资、灵动岛全部可用，只是聊天和双人同步不可用。
以后想连服务器：我的 → 退出登录 → 回登录页填地址登录，**本机账本与密码本会保留**。

**Q：App 里「测试连接」失败？**
按顺序排查：
1. 手机上浏览器能否打开 `http://服务器IP:8787/api/health`？打不开说明服务没起或端口不通
2. 两台手机填的地址是否完全一致
3. 服务器防火墙是否放行了 8787（公网建议只开 80/443 走 Nginx）
4. 局域网地址（`192.168.x.x`）在 4G/5G 下访问不了，是正常的
5. 地址不要带 `/api` 后缀

**Q：聊天消息发不出去，但有历史记录？**
WebSocket 没连上：
- 反向代理必须配置 `Upgrade` / `Connection` 两行（见 [03-服务器部署.md](03-服务器部署.md) 的 Nginx 示例）
- 宝塔面板需要在反向代理里开启 WebSocket 支持
- 看 App 聊天页顶部的小圆点：绿色=已连接，红色=连接中

**Q：两台手机数据不同步？**
1. 「我的 → 服务器与同步」看同步状态和上次同步时间
2. 点「立即同步」
3. 还是不行 → 点「重置同步」（下次全量拉取）
4. 确认两台手机都填了同一个服务器地址、并且已经绑定情侣关系

**Q：换手机 / 重装 App 后数据没了？**
服务器上的数据（聊天、火花、宠物、签到、愿望、加班）会在登录后自动拉回来。
**记账和密码本只存在本机，重装会丢**，请提前用「导出本机数据」备份。

**Q：服务器换了地址怎么办？**
App「我的 → 服务器设置」改地址即可，数据在服务器上，不受影响。

## D. AI 记账

**Q：提示「AI 未配置」？**
去后台 `/admin` 填 DeepSeek API Key。见 [04-后台管理.md](04-后台管理.md)。

**Q：没配 Key 能不能记账？**
能。App 会自动用**本地规则解析**（识别"午饭25"这类常见说法），完全离线。

**Q：识别不准？**
- 尽量用「项目 + 金额」的写法：`午饭25，打车18.5，买菜83.6`
- 切换成 `deepseek-chat` 模型通常比 `deepseek-reasoner` 更快更稳
- 识别结果在保存前是**可以逐条修改**的（金额、分类、备注都能改）

**Q：账单会不会被上传？**
不会。只有你输入的那句话会发给服务器做识别，识别完即丢弃；账目明细只写本机文件，也不参与情侣同步。

**Q：AI 月报上传了什么？**
只上传「该月支出/收入总额 + 分类汇总」这些数字，不含任何单笔明细和备注。

## E. 灵动岛

**Q：灵动岛不显示？**
逐条确认：
1. 装的是**完整版**（我的 → 关于 → 安装包类型应显示「完整版（含灵动岛扩展）」）
2. 机型是 iPhone 14 Pro 及以上（灵动岛需要硬件支持；非灵动岛机型只在锁屏显示）
3. 系统 ≥ iOS 16.1
4. 设置 → 情侣空间 → **实时活动** 是打开的
5. 首页「灵动岛」卡片 → 点「开启灵动岛」

**Q：轻量版就没有灵动岛了吗？**
轻量版没有小组件扩展，无法上岛。首页会用一张同样外观的「灵动岛卡片」显示在一起天数、加班计时、火花，功能都能用。

**Q：计时器会不会停？**
灵动岛上的计时器由系统渲染，App 退到后台也会继续走。但**内容更新**需要 App 在前台时触发。

**Q：关闭灵动岛？**
首页灵动岛卡片 → 点「关闭」；或在「我的 → 外观与体验」里关掉「启用灵动岛」。

## F. 数据与隐私

**Q：谁知道我的数据？**
- 记账、密码本：只有你的手机知道，服务器完全收不到
- 聊天、火花、宠物、签到、愿望、加班记录：存在**你自己的服务器**上，不经过任何第三方
- AI 记账：只有你输入的那句话会经过 DeepSeek

**Q：密码本忘了主密码？**
无法找回（这是加密的设计目的）。在解锁页连续输错 3 次后会出现「清空密码本」按钮。

**Q：怎么彻底清空？**
我的 → 数据与隐私 → 清空全部本地数据；服务端数据可以删掉 `server/data/` 目录，或在后台删除用户。

**Q：能导出账单吗？**
我的 → 数据与隐私 → 导出本机数据（JSON），包含账本、设置等本机数据（**不含密码本明文**）。

## G. 其它

**Q：App 名字能改吗？**
改 `ios/Support/App-Info.plist` 里的 `CFBundleDisplayName`（默认「情侣空间」）。

**Q：想换 App 图标？**
改 `tools/make-icon.mjs` 里的配色/图形后运行 `node tools/make-icon.mjs`，或直接替换
`ios/Sources/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`（1024×1024 PNG，不要透明通道）。

**Q：想加功能怎么办？**
代码分层清晰，一般加功能只需要：
1. `Models/` 加数据模型（记得写 `init?(json:)` 容错解析）
2. `Core/LocalStore.swift` 加业务方法
3. `Features/` 加页面
4. 需要同步的话，在 `SyncEngine.localSyncObjects()` 和 `apply(_:)` 里加分支，并在 `docs/API.md` 更新 kind 白名单

**Q：会不会有版权问题？**
内置的表情是「emoji + 配色 + 文案」现场绘制，不含任何第三方素材；项目仅供个人自用，请不要上架或商用。
