# 08 · 验收清单（照着打勾就行）

从零到两台手机都能用，按顺序做，每一步都有"怎么判断成功"。

---

## 阶段一：拿到 IPA（约 15 分钟）

- [ ] **1. 注册 GitHub 账号**（已有可跳过）
- [ ] **2. 新建仓库**：https://github.com/new → 名字随意（如 `couple-app`）→ 建议选 **Public** → 不要勾 README
- [ ] **3. 推送代码**：在项目根目录打开 PowerShell

  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts\push-to-github.ps1 -RepoUrl "https://github.com/你的用户名/couple-app.git"
  ```

  ✅ 成功标志：脚本最后出现 `✅ 推送完成！`
  ❌ 提示找不到 git → 装 [Git for Windows](https://git-scm.com/downloads) 后重开 PowerShell

- [ ] **4. 触发构建**：GitHub 仓库页 → **Actions** → 左侧「构建 iOS IPA」→ **Run workflow** → 版本选 `all` → 绿色按钮
- [ ] **5. 等绿灯**：三个任务都变 ✅（Swift 语法检查、服务端测试、构建 IPA），约 5～8 分钟
- [ ] **6. 下载 IPA**：点进「构建 IPA」任务 → 页面底部 **Artifacts** → 下载
  - `CoupleApp-unsigned-ipa` = 完整版（含灵动岛）
  - `CoupleAppLite-unsigned-ipa` = 轻量版（无扩展）
  - 下载的是 zip，**解压后才是 .ipa**

✅ 阶段完成标志：本机有了一个 `.ipa` 文件

---

## 阶段二：安装到 iPhone（约 10 分钟）

- [ ] **7. 判断该装哪个版本**：看 [01-签名证书判断.md](01-签名证书判断.md) 的对照表
  - 不确定 → **先装轻量版**
- [ ] **8. 用你的 P12 签名并安装**（爱思助手 / ESign / Sideloadly 任选，步骤见 [01](01-签名证书判断.md)）
- [ ] **9. 手机上信任证书**：设置 → 通用 → VPN与设备管理 → 信任

✅ 阶段完成标志：桌面上出现「情侣空间」图标，点开能进登录页

> 💡 此时已经可以点登录页的「**本机单机使用**」先用起来（记账、密码本、宠物、签到、愿望、加班、灵动岛都能用）。

---

## 阶段三：部署服务器（约 20 分钟，想要聊天和双人同步才需要）

- [ ] **10. 准备一台服务器**（云服务器 / NAS / 家里常开的电脑）
- [ ] **11. 装 Node 20+**：

  ```bash
  curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt install -y nodejs
  ```

- [ ] **12. 上传 server 目录并安装**：

  ```bash
  cd /opt/couple-server        # 你放 server 的目录
  cp .env.example .env
  nano .env                    # 填 JWT_SECRET 和 ADMIN_PASSWORD
  npm install
  npm start
  ```

  ✅ 成功标志：控制台打印 `✅ 情侣空间服务端已启动` 和两个网址
  ❌ 提示缺少 JWT_SECRET → 就是让你去 `.env` 里填，生成命令在文件注释里

- [ ] **13. 放行防火墙 / 配 HTTPS**：见 [03-服务器部署.md](03-服务器部署.md) 第四节
- [ ] **14. 验证**：手机浏览器打开 `http://你的地址:8787/api/health`，能看到 `{"ok":true,...}`

---

## 阶段四：配置 AI 记账（约 5 分钟）

- [ ] **15. 申请 DeepSeek Key**：https://platform.deepseek.com → API Keys → 创建 → 复制（`sk-` 开头）→ 充值
- [ ] **16. 浏览器打开后台** `https://你的地址/admin`，用 `ADMIN_PASSWORD` 登录
- [ ] **17. 粘贴 Key → 选 `deepseek-chat` → 打开「启用 AI」→ 保存**
- [ ] **18. 点「测试」**，输入 `午饭25，打车18.5`，返回两条账目即成功

---

## 阶段五：两个人连起来

- [ ] **19. 两台手机都装好 App**，登录页都填**同一个服务器地址**，点「测试连接」确认成功
- [ ] **20. 手机 A**：注册账号 → 我的 → 创建情侣空间 → 拿到 6 位邀请码
- [ ] **21. 手机 B**：注册账号 → 我的 → 输入邀请码 → 绑定
- [ ] **22. 双向验证**：A 发一条消息，B 应立刻收到（聊天页顶部小圆点是绿色）

## 阶段六：15 项功能逐个验收

| # | 功能 | 怎么验 | 期望结果 |
| --- | --- | --- | --- |
| 1 | App 能装能开 | 点开图标 | 进入登录页/主界面 |
| 2 | P12 签名 | 已装成功 | 图标可点、不闪退 |
| 3 | 火花系统 | 首页 → 火花卡 → 点「戳一戳」 | 火花值增加，30 天日历点亮格 |
| 4 | 表情 | 聊天页 → 点笑脸 → 「抖音表情」/「我的表情包」 | 内置风格表情可发；上传的图能发出去 |
| 5 | 养宠物 | 宠物页 → 喂食 / 陪玩 | 饱食度、心情、经验变化，有金币奖励 |
| 6 | 签到 | 首页 → 签到 → 选心情 → 立即签到 | 金币 +20 起，连续天数 +1，日历出现粉点 |
| 7 | 愿望 | 首页 → 愿望 → 右上角 + | 新增愿望，能存入金币，进度条前进 |
| 8 | AI 记账 | 账本 → 用一句话记账 → 输入「午饭25，打车18.5」→ 识别 | 拆成 2 笔，可改分类，保存后只在本机 |
| 9 | 加班工资 | 首页 → 加班工资 → 上班打卡 → 下班打卡 → 填加班时长 | 应发合计 = 工时×时薪 + 加班×时薪×倍率 |
| 10 | 灵动岛 | 首页灵动岛卡 → 选样式 → 开启灵动岛 | 顶部/锁屏出现实时活动（轻量版显示卡片） |
| 11 | 聊天 | 两台手机互发文字/表情 | 秒收；对方看得到「已读」；断开重连后仍可发 |
| 12 | 密码管理 | 我的 → 密码本 → 创建主密码 → 新增条目 | 能保存、能 Face ID 解锁、复制密码 |
| 13 | 登录系统 | 退出登录再登回来 | 账号密码可登；未绑定有邀请码流程 |
| 14 | 版本号 | 登录页 / 首页底部 / 我的 → 关于 | 显示 `v1.0.0 (1)` |
| 15 | 走服务器 | 我的 → 服务器与同步 → 立即同步 | 状态显示「已同步 刚刚」 |

## 阶段七：确认隐私边界（重要）

- [ ] **23. 记账只在本机**：在 A 手机记一笔账，B 手机的账本**不应**出现这笔（这是设计如此）
- [ ] **24. 密码本只在本机**：B 手机看不到 A 的密码本（也不联网）
- [ ] **25. 聊天/宠物/签到/愿望/加班是共享的**：这些会双向同步
