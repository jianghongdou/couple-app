# 03 · 服务器部署

服务端负责：账号登录、情侣绑定、聊天（WebSocket）、双人同步、表情包存储、DeepSeek 代理、后台管理。

> 💡 **不想装 Node？** 本项目还有一份 **PHP 版服务端**，接口契约完全相同、宝塔上零依赖（不用 npm / 不用原生模块），
> 见 **[10-PHP服务端部署.md](10-PHP服务端部署.md)**。两者的功能与 API 一致，任选其一部署即可。

- 语言：Node.js（**20 及以上**，已在 Node 24 上验证）
- 数据库：SQLite（单文件，零运维）
- 占用：内存约 80MB，磁盘很低（表情包图片占主要空间）

> 不部署服务器也能用 App，只是两台手机不互通（记账、密码本、宠物、签到依然可用）。

---

## 一、准备

你需要一台**两台手机都能访问到**的机器：

| 场景 | 可行性 |
| --- | --- |
| 云服务器（阿里云/腾讯云/VPS） | ✅ 最推荐，公网可访问 |
| 家里的旧电脑 / NAS / 树莓派 | ✅ 两台手机连同一个 WiFi 时可用；想在外面用需要内网穿透 |
| 只有一台电脑偶尔开机 | ⚠️ 电脑关机后聊天和同步就断了，但本地功能不受影响 |

**公网服务器强烈建议配 HTTPS**（iOS 对明文 HTTP 有限制，虽然本项目已在 Info.plist 里放开，但 HTTPS 更安全，也不容易被运营商劫持）。

## 二、方式 A：直接跑（最快）

```bash
# 1) 上传代码 ⚠️ 必须排除 node_modules（原因见下方红框）
#    推荐 rsync，它会跳过 node_modules / data / .env：
rsync -av --exclude node_modules --exclude data --exclude .env \
      server/ root@你的服务器:/opt/couple-server/

#    没有 rsync 就先压包再传（同样排除 node_modules）：
#    tar czf server.tgz --exclude=node_modules --exclude=data server/
#    scp server.tgz root@你的服务器:/opt/
#    ssh root@你的服务器 'cd /opt && tar xzf server.tgz && mv server couple-server'

ssh root@你的服务器
cd /opt/couple-server

# 2) 安装 Node 20+（Debian/Ubuntu 示例）
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs

# 3) 配置环境变量
cp .env.example .env
nano .env       # 至少改 JWT_SECRET 和 ADMIN_PASSWORD

# 4) 在服务器上安装依赖（这一步必须在服务器上做！）
npm install

# 5) 自检 + 启动
npm run doctor  # 一键环境体检，有问题会直接告诉你怎么办
npm start
```

> 🚫 **千万不要把本机的 `node_modules` 文件夹传上服务器**
>
> `better-sqlite3` 是**原生模块**，二进制按操作系统编译。Windows/macOS 上装的 `.node` 文件在 Linux 上一定加载失败，报错长这样：
>
> ```
> at bindings (.../node_modules/bindings/bindings.js:112:48)
> at new Database (.../node_modules/better-sqlite3/lib/database.js:48:64)
> { code: 'ERR_DLOPEN_FAILED' }
> ```
>
> **修复（在 server 目录下执行）**：
>
> ```bash
> rm -rf node_modules
> npm install
> npm run doctor          # 确认平台匹配
> npm start
> ```
>
> 若 `npm install` 拉不到预编译二进制，再执行 `npm run fetch-sqlite`（从国内镜像单独下载）。

看到日志出现监听地址（默认 `http://0.0.0.0:8787`）就成功了。用浏览器访问 `http://服务器IP:8787/api/health` 应返回 `{"ok":true,...}`。

> 📦 关于 `server/.npmrc`：里面把 npm 源指向了国内镜像 `registry.npmmirror.com`，在国内服务器上安装快很多。
> 如果你的服务器在国外，或者安装报错，可以删掉这个文件（或改成 `registry=https://registry.npmjs.org/`）再装。
> 如果 `better-sqlite3` 下载预编译二进制失败，执行 `npm run fetch-sqlite` 从镜像重新拉取。

### 生成随机密钥

```bash
# Linux / macOS
openssl rand -hex 32
# Windows PowerShell
-join ((1..64) | ForEach-Object { '{0:x}' -f (Get-Random -Max 16) })
```

### 用 systemd 开机自启（推荐）

```bash
cat >/etc/systemd/system/couple-server.service <<'EOF'
[Unit]
Description=Couple App Server
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/couple-server
ExecStart=/usr/bin/node src/index.js
Restart=always
RestartSec=3
User=root
EnvironmentFile=/opt/couple-server/.env

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now couple-server
systemctl status couple-server
journalctl -u couple-server -f      # 看日志
```

### 用 pm2（更灵活）

```bash
npm install -g pm2
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

## 四、配置 HTTPS（强烈建议）

### 方案 1：Caddy（自动申请证书，最简单）

装好 Caddy 后写 `/etc/caddy/Caddyfile`：

```
couple.你的域名.com {
    reverse_proxy 127.0.0.1:8787
}
```

```bash
systemctl reload caddy
```

Caddy 会自动申请并续期 Let's Encrypt 证书，WebSocket 也会自动转发。

### 方案 2：Nginx

```nginx
server {
    listen 443 ssl http2;
    server_name couple.你的域名.com;

    ssl_certificate     /etc/letsencrypt/live/couple.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/couple.你的域名.com/privkey.pem;

    client_max_body_size 8m;    # 表情包上传

    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_http_version 1.1;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 升级（聊天必须）
        proxy_set_header Upgrade    $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }
}

server {
    listen 80;
    server_name couple.你的域名.com;
    return 301 https://$host$request_uri;
}
```

项目里也附带了 `server/nginx.conf.example`。

### 方案 3：宝塔面板

1. 新建站点 → 绑定域名
2. 反向代理 → 目标 `http://127.0.0.1:8787`
3. 打开「SSL」申请免费证书
4. 在反向代理配置里加上 WebSocket 的两行 `Upgrade` / `Connection`（宝塔默认会加）

### 防火墙

只放行 80 / 443，**不要**把 8787 直接暴露到公网。

```bash
ufw allow 80
ufw allow 443
ufw deny 8787
```

## 五、客户端怎么填地址

| 环境 | App 里填 |
| --- | --- |
| 公网 + HTTPS | `https://couple.你的域名.com` |
| 局域网 | `http://192.168.1.10:8787` |
| 内网穿透 | 穿透工具给你的域名 |

注意：
- **不要**带 `/api` 后缀，程序会自动加
- 不带 `http://` 时会自动补 `http://`
- 两台手机必须填**完全一样**的地址
- 登录页点「配置」可以随时改

## 六、备份与升级

### 备份

所有数据都在 `server/data/` 目录（SQLite 文件 + 表情图片）：

```bash
# 停服备份最稳妥
systemctl stop couple-server
tar czf couple-backup-$(date +%F).tar.gz -C /opt/couple-server data
systemctl start couple-server
```

建议加个每日定时任务。

### 升级

```bash
cd /opt/couple-server
systemctl stop couple-server
tar czf backup-before-upgrade.tar.gz data       # 先备份
# 覆盖新的代码文件（保留 .env 和 data）
npm install
systemctl start couple-server
```

数据库结构会在启动时自动创建/补齐，不需要手动迁移。

## 七、验证清单

部署完成后逐条检查：

- [ ] `curl http://127.0.0.1:8787/api/health` 返回 `ok: true`
- [ ] 浏览器能打开 `https://你的域名/api/meta`
- [ ] 浏览器能打开 `https://你的域名/admin`（后台登录页）
- [ ] 手机上 App 填地址后点「测试连接」提示成功
- [ ] 两台手机分别注册 → 一台建情侣空间 → 另一台用邀请码绑定成功
- [ ] 互发一条聊天消息，能实时收到
- [ ] 后台填好 DeepSeek Key 后，账本里「一句话记账」能识别

## 八、环境变量说明

| 变量 | 是否必填 | 说明 |
| --- | --- | --- |
| `PORT` | 否 | 监听端口，默认 8787 |
| `DATA_DIR` | 否 | 数据目录，默认 `./data` |
| `JWT_SECRET` | **必填** | 用户登录 token 密钥，≥32 位随机串，泄露等于所有账号被冒充 |
| `ADMIN_PASSWORD` | **必填** | 后台管理密码 |
| `ADMIN_JWT_SECRET` | 否 | 默认复用 `JWT_SECRET` |
| `PUBLIC_BASE_URL` | 否 | 生成表情绝对地址用，留空即可 |
| `TRUST_PROXY` | 否 | 前面有 Nginx 时保持默认 `1` |
| `LOG_LEVEL` | 否 | `info` / `debug` / `warn` |
