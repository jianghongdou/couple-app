# 02 · 云编译出 IPA 并安装到 iPhone

本机不需要 Mac、不需要 Xcode。编译交给 GitHub 免费的 macOS 云机器。

---

## 第 0 步：准备

- 一个 GitHub 账号（免费注册）
- 电脑上装好 **Git**（Windows 也可以，项目里已经包含推送脚本）
- 手机上的签名工具（见 [01-签名证书判断.md](01-签名证书判断.md)）

---

## 第 1 步：把代码传到 GitHub

### 1.1 在 GitHub 网页上新建仓库

1. 打开 https://github.com/new
2. Repository name 随便填，例如 `couple-app`
3. **建议选 Public**：公开仓库的 Actions 分钟数完全免费、不限量；Private 仓库每月只有 2000 分钟（本项目构建一次约 5～8 分钟，也够用，但公开更省心）
4. **不要**勾选 "Add a README file"
5. 点 Create repository，记下页面显示的仓库地址，例如 `https://github.com/你的用户名/couple-app.git`

### 1.2 在电脑上推送代码

本项目根目录下已提供脚本：

```powershell
# 在项目根目录（有 要求.txt 的这一层）打开 PowerShell
powershell -ExecutionPolicy Bypass -File scripts\push-to-github.ps1 -RepoUrl "https://github.com/你的用户名/couple-app.git"
```

脚本会自动完成：`git init` → 提交全部文件 → 添加远程 → 推送。

> 第一次推送会弹出登录窗口（Git Credential Manager），用浏览器登录 GitHub 授权即可。
> 如果提示要先拉取：`git pull --rebase origin main`，再 `git push -u origin main`。

手动方式（不想用脚本）：

```powershell
git init
git add .
git commit -m "情侣空间 App 首次提交"
git branch -M main
git remote add origin https://github.com/你的用户名/couple-app.git
git push -u origin main
```

---

## 第 2 步：在 GitHub 上跑构建

1. 打开你的仓库页面 → 顶部 **Actions** 标签
2. 如果提示 "Workflows aren't being run on this repository"，点 **I understand my workflows, go ahead and enable them**
3. 左侧选 **构建 iOS IPA** → 右侧 **Run workflow** 按钮
4. `构建哪个版本` 选择：
   - `all` —— 完整版 + 轻量版都构建（**推荐**）
   - `full` —— 只要完整版（含灵动岛）
   - `lite` —— 只要轻量版
5. 点绿色的 **Run workflow**

构建流程会依次跑三个任务：

| 任务 | 作用 | 通常耗时 |
| --- | --- | --- |
| Swift 语法检查 | 快速检查代码语法 | 1 分钟 |
| 服务端测试 | 跑 Node 服务端冒烟测试 | 1～2 分钟 |
| 构建 IPA | 真正编译 iOS 包 | 5～8 分钟 |

### 下载 IPA

构建完成后（页面出现绿色 ✅）：

1. 点进 **构建 IPA** 这个任务
2. 页面最下方 **Artifacts** 区域
3. 下载：
   - `CoupleApp-unsigned-ipa` → **完整版**（含灵动岛）
   - `CoupleAppLite-unsigned-ipa` → **轻量版**（无扩展）
4. 下载下来是 `.zip`，解压后里面就是 `.ipa` 文件

> ⚠️ Artifacts 有保存期限（默认 90 天），到期需要重新跑一次构建。
> ⚠️ 想长期保存：给仓库打个 tag（如 `v1.0.0`）并 push，工作流会自动构建并把 IPA 挂到 Release 页面，永久可下载。

## 第 3 步：签名并安装

按 [01-签名证书判断.md](01-签名证书判断.md) 里的三种方式任选一种（爱思助手 / ESign / Sideloadly）。

**关键步骤（无论用哪种工具都一样）：**

1. 把 IPA 导入签名工具
2. 选择你的证书（p12 + 密码；如果有描述文件就一起选）
3. 开始签名 → 安装到设备
4. iPhone 上信任证书：**设置 → 通用 → VPN与设备管理 → 找到你的证书 → 信任**
5. 打开 App，第一件事是填服务器地址（如果服务器已经部署好）

---

## 第 4 步：两台手机都装上

1. 两台 iPhone 都按上面步骤装好 App
2. 都在登录页把**服务器地址填成同一个**
3. 手机 A 注册账号 → 我的 → 创建情侣空间 → 得到 6 位邀请码
4. 手机 B 注册账号 → 我的 → 输入邀请码 → 绑定
5. 绑定成功后：聊天、火花、宠物、签到、愿望、加班记录会自动双向同步

## 常见构建问题

| 现象 | 原因 / 解决 |
| --- | --- |
| Actions 页面没有工作流 | 仓库里没有 `.github/workflows/ios-build.yml`，确认文件已推送 |
| 构建失败在 "生成 Xcode 工程" | `brew install xcodegen` 那步失败，重新跑一次即可（网络抖动） |
| 构建失败在 "开始编译" | 代码问题。把日志最后 60 行复制出来，见 [07-编译失败怎么反馈.md](07-编译失败怎么反馈.md) |
| Artifacts 是空的 | 构建那一步失败了，日志里会写明原因 |
| 下载的 IPA 装不上 | 是「未签名」IPA，必须先用自己的证书签名，不能直接安装 |
| macOS runner 排队很久 | 免费额度在高峰期会排队，等几分钟或换个时间 |

## 本机有 Mac 怎么办

Mac 上更简单，不需要 Actions：

```bash
brew install xcodegen
cd ios
xcodegen generate
open CoupleApp.xcodeproj
```

然后在 Xcode 里：
1. 选中 `CoupleApp` target → Signing & Capabilities → 勾选 Automatically manage signing → 选择你的 Team
2. 把两个 target（`CoupleApp` 和 `CoupleWidgets`）的 **Bundle Identifier** 改成你自己唯一的（例如 `com.你的名字.coupleapp` 和 `com.你的名字.coupleapp.widget`）
3. 连上 iPhone，选真机 → Run

> Xcode 会自动帮你申请描述文件，两种版本都能装，也是唯一能「自动处理扩展签名」的方式。
