# 11 · WordPress 插件版部署（宝塔，最省事）

> 插件目录：`wordpress-plugin/couple-space/`
> 接口契约与 PHP 版 / Node 版**完全一致**（见 [API.md](API.md)），iOS App 不需要任何改动。
> 适合已经在宝塔上一键装了 WordPress 的情况：**上传插件 → 启用 → 填地址**，不用碰目录、不用改 nginx。

---

## 一、为什么是插件而不是主题

| | 插件 | 主题 |
| --- | --- | --- |
| 能否注册 App 需要的 `/api/...` 接口 | ✅ 可以 | ❌ 不行 |
| 换主题后是否失效 | 不受影响 | 会失效 |
| 后台设置页 | WP 原生菜单 | 要挤进主题选项 |

---

## 二、安装（3 步）

1. WordPress 后台 → **插件 → 安装插件 → 上传插件**
2. 选择 `couple-space-plugin-<日期>-<时间>.zip` → **现在安装** → **启用插件**
3. 启用时插件会自动建表（`wp_couple_users`、`wp_couple_messages` 等），无需手动操作

**必做的一步：设置固定链接**

> WP 后台 → **设置 → 固定链接** → 选择「**文章名**」(`/%postname%/`) → 保存。
> 不设置的话 `/api/...` 形式的接口地址不会生效（App 里就要改用插件「服务器信息」页显示的另一种地址）。

---

## 三、配置

WP 后台左侧会出现「**情侣空间**」菜单：

| 分区 | 用途 |
| --- | --- |
| 总览 | 用户数、情侣数、消息数、表情数、今日 AI 调用 |
| AI 设置 | 填 DeepSeek API Key（[申请](https://platform.deepseek.com)）、模型、开关、每日限额、**测试**按钮 |
| 应用设置 | 开放注册开关（两人用建议关掉）、公告、最低/最新版本号、更新地址、表情包上限、每日消息上限 |
| 用户管理 | 搜索、重置密码、禁用/启用、删除 |
| 安全 | 修改**后台管理员密码**（App 里 `/admin.php` 那个，与 WP 用户无关） |
| 统计 / 操作日志 | 数据与审计 |
| **服务器信息** | 数据库与表状态、**App 里该填哪个地址**、密码来源 |

---

## 四、App 里填什么地址

打开「情侣空间 → **服务器信息**」，页面会直接告诉你该填哪个（自动检测），一般是：

| 情况 | App 里填 |
| --- | --- |
| 固定链接已设为「文章名」（推荐） | `https://你的域名` |
| 固定链接没设置 | `https://你的域名/wp-json/couple/v1` |

两种插件都支持；末尾不要加 `/api`。两台手机填**同一个地址**。

---

## 五、聊天为什么显示「轮询刷新中（5 秒）」

WordPress 里不适合常驻 WebSocket 进程，所以插件不提供实时推送。App 会自动降级成**每 5 秒轮询**：

- 消息照常收发，只是有最多 5 秒延迟
- 聊天页顶部会显示「轮询刷新中（5 秒）」，这是正常状态
- 想要实时推送，就改用 PHP 版 + `bin/ws-server.php`（见 [10-PHP服务端部署.md](10-PHP服务端部署.md)）

## 六、排错

| 现象 | 处理 |
| --- | --- |
| `/api/health` 返回 404 | 固定链接没设置 → 按第二节设为「文章名」；或 App 改填 `/wp-json/couple/v1` 形式 |
| 插件启用时报错 | 看 WP 后台顶部提示；多半是数据库权限或 PHP 版本（需要 8.1+） |
| App「测试连接」失败 | 确认 App 地址没写错、服务器能出网；插件「服务器信息」页有自检结果 |
| 上传表情失败 | `wp-content/uploads/` 不可写 → `chown -R www:www wp-content/uploads` |
| AI 报「AI 未配置」 | 插件「AI 设置」里没填 DeepSeek Key |
| 想改 App 后台管理员密码 | 插件「安全」分区，或 `wp couple-space set-admin-password 新密码`（WP-CLI） |
| 卸载插件后数据还在吗 | 默认保留；`uninstall.php` 会按选项决定是否清理，删插件前建议先备份 |

## 八、和 PHP 版 / Node 版的关系

三套实现的**接口完全一致**，App 任选其一（只能填一个服务器地址）：

| 版本 | 适合 |
| --- | --- |
| **WordPress 插件**（本文） | 已经装了 WP、想用熟悉的方式管理、不介意聊天延迟 5 秒 |
| PHP 版 `server-php/` | 想要实时聊天（带 WebSocket 常驻进程）、不用 WordPress |
| Node 版 `server/` | 有 Node 环境或跑 Docker |
