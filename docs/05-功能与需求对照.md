# 05 · 功能与需求对照

`要求.txt` 里的 15 条需求，逐条说明实现方式和代码位置。

---

### 1、可以在 iPhone 上运行的 App

原生 **SwiftUI** 应用，最低支持 **iOS 16.1**，只做 iPhone 竖屏。
底部 5 个标签页：首页 / 聊天 / 宠物 / 账本 / 我的。

- 入口：`ios/Sources/App/CoupleAppMain.swift`
- 标签页：`ios/Sources/App/MainTabView.swift`

---

### 2、个人 P12 签名

代码本身不涉及签名，交付的是**未签名 IPA + 完整签名指南**：

- 云端编译：`.github/workflows/ios-build.yml`
- 构建脚本：`scripts/build-ipa.sh`
- 证书判断：`docs/01-签名证书判断.md`
- 安装步骤：`docs/02-云编译与安装.md`

提供两个安装包：

| 包 | Bundle ID | 说明 |
| --- | --- | --- |
| 完整版 | `com.coupleapp.ios` | 含 `CoupleWidgets.appex`，能上灵动岛 |
| 轻量版 | `com.coupleapp.ios.lite` | 无扩展，对证书要求最低 |

---

### 3、火花系统

火花值、等级（11 级）、连续天数、历史最长、30 天点亮日历、7 个里程碑、每日上限 40 点。

- 模型：`ios/Sources/Models/InteractionModels.swift` → `SparkState`
- 逻辑：`ios/Sources/Core/LocalStore.swift` → `addSpark(points:reason:)`
- 页面：`ios/Sources/Features/Spark/SparkView.swift`

获得途径：聊天 +1、签到 +10~30、喂宠物 +3、许愿 +5、记账 +1、戳一戳 +5、送爱心 +8。

---

### 4、抖音表情 + 自己上传表情包

三种表情来源：

1. **内置 Unicode 表情**：7 个分组约 170 个（`ios/Sources/Core/EmojiLibrary.swift`）
2. **「抖音风格」表情**：24 款用 emoji + 文案 + 渐变配色现场绘制（`BuiltinStickers`），不包含任何第三方版权素材
3. **自定义表情包**：从相册选图 → 自动压缩到 400KB 以内 → 上传到**你自己的服务器** → 双方都能用

- 渲染：`ios/Sources/Features/Chat/MessageRow.swift`（`StickerView`）
- 面板：`ios/Sources/Features/Chat/EmojiPanelView.swift`
- 上传管理：`ios/Sources/Features/Chat/EmojiPackManageView.swift`
- 上传接口：`POST /api/emoji/items`（见 `docs/API.md`）

---

### 5、养宠物

饱食度 / 心情值 / 精力值三条状态、经验等级、金币、9 种形象（部分需要金币解锁）、可上传自己拍的照片当宠物。
每 2 小时状态自然衰减，需要人来照顾；宠物由两人共同照料（状态同步）。

- 模型：`PetState`
- 逻辑：`LocalStore` → `feedPet` / `playWithPet` / `sleepPet` / `buyPetSpecies` / `applyPetDecayIfNeeded`
- 页面：`ios/Sources/Features/Pet/PetView.swift`

---

### 6、签到系统

每日签到（可写心情和一句话）、连续签到奖励递增（20 + 天数×2，上限 50 金币）、
双人签到日历（粉色=我，紫色=TA）、金币补签（50 金币/天）。

- 逻辑：`LocalStore` → `checkIn` / `makeupCheckIn` / `checkInStreak`
- 页面：`ios/Sources/Features/CheckIn/CheckInView.swift`

---

### 7、愿望系统

愿望清单（分类 + 详情 + 需要多少金币）、两人共同往愿望里存金币、惊喜愿望（实现前对方看不到内容）、
标记实现、进度条。

- 模型：`Wish`
- 逻辑：`LocalStore` → `addWish` / `contributeToWish` / `fulfillWish`
- 页面：`ios/Sources/Features/Wish/WishView.swift`

---

### 8、接入 AI 记账，该记账只存在本地

- **AI**：DeepSeek，Key 只存在**服务器后台**（见 `docs/04-后台管理.md`）
- **本地**：账目写入 `Application Support/CoupleApp/state.json`，**永远不上传、不参与同步**
- 服务端只做「一句话 → 结构化金额」的转换，账单明细不落库
- 离线或没配 Key 时，自动用**本地规则解析**兜底（`LocalLedgerParser`，约 13 类关键词）

- 服务：`ios/Sources/Services/LedgerAIService.swift`
- 页面：`ios/Sources/Features/Ledger/LedgerView.swift`、`LedgerEntryViews.swift`
- 服务端接口：`POST /api/ai/parse-ledger`、`POST /api/ai/monthly-report`

功能：一句话拆多笔、手动记账、编辑/删除、分类排行、7 天柱状图、月度预算、AI 月度总结。

---

### 9、每日上班加班记录（记录工资）

- 上班打卡 / 下班打卡（首页卡片上有实时计时器）
- 加班时长（0～12 小时，0.5 小时步进）
- 工资计算：`正常工时 × 时薪 + 加班时长 × 时薪 × 倍率`，可设 1x / 1.5x / 2x / 3x
- 月度统计：出勤天数、总工时、加班工时、基本工资、加班工资、应发合计
- 支持请假（事假/病假/年假/调休/婚假/产假，不计薪）
- 打卡记录同步给伴侣（能看到对方"加班中"）

- 模型：`WorkLog`（`ios/Sources/Models/WorkModels.swift`）
- 页面：`ios/Sources/Features/Work/WorkLogView.swift`

### 10、苹果灵动岛信息

三种样式：

| 样式 | 显示内容 |
| --- | --- |
| 在一起天数 | ❤️ + 「在一起 N 天」+ 纪念日进度 |
| 加班计时 | 💼 + 自动走秒的计时器（App 退到后台也继续走） |
| 火花 | 🔥 + 火花值 + 连续天数 |

- 数据模型（App 与扩展共用）：`ios/Sources/Features/Live/Shared/CoupleActivityAttributes.swift`
- 小组件 UI：`ios/Sources/Features/Live/Widget/CoupleLiveActivityWidget.swift`
- 控制器：`ios/Sources/Features/Live/LiveActivityController.swift`
- 开关与预览：`ios/Sources/Features/Home/LiveIslandCard.swift`

> ⚠️ 灵动岛必须由**内嵌小组件扩展**的完整版提供。装了轻量版时，首页会用一张「灵动岛样式」的卡片显示同样的信息，功能不受影响。
> 另外需要 iPhone 14 Pro 及以上机型 + iOS 16.1+，并在 设置 → 情侣空间 里打开「实时活动」。

### 11、聊天功能

- 实时：`URLSessionWebSocketTask`，收到消息即时上屏，带「对方正在输入」、在线状态
- 消息类型：文字、Unicode 表情、抖音风格表情、自定义表情包图片
- 已读回执、消息时间、发送中/失败状态（失败点一下重发）
- 断线自动重连（1s→2s→4s→8s→15s→30s 退避），历史消息分页加载（每次 50 条）
- 未读数量角标显示在底部「聊天」标签上
- 收到消息时如果不在聊天页，顶部弹出横幅，点一下跳转

- 服务：`ios/Sources/Services/ChatService.swift`、`ios/Sources/Core/RealtimeClient.swift`
- 页面：`ios/Sources/Features/Chat/ChatView.swift`

---

### 12、密码管理功能

- 主密码派生密钥（PBKDF2-HMAC-SHA256，10 万次迭代，纯 CryptoKit 实现）
- 数据用 **AES-GCM** 加密后存本机文件，密钥放系统钥匙串
- Face ID / 指纹快速解锁
- 条目分类（网站/账号/银行卡/证件/WiFi/其它）、搜索、收藏、密码强度提示、18 位随机密码生成、复制后 30 秒自动清空剪贴板
- **不联网、不上传、不参与同步**；忘记主密码只能清空重来

- 加密：`ios/Sources/Core/CryptoBox.swift`
- 存取：`ios/Sources/Core/LocalStore.swift`（vault 部分）
- 页面：`ios/Sources/Features/Vault/VaultView.swift`

---

### 13、登录系统

- 注册 / 登录（用户名 3-32 位字母数字下划线，密码 ≥6 位）
- 服务端 bcrypt 存密码、JWT（30 天）鉴权
- 修改密码、修改昵称头像
- 情侣绑定：一方创建情侣空间生成 6 位邀请码，另一方输入邀请码绑定
- 注册时可以直接填邀请码一步绑定
- 登录过期自动退回登录页；服务器异常时仍可查看本机数据

- 页面：`ios/Sources/Features/Auth/LoginView.swift`、`ServerSetupView.swift`
- 服务：`ios/Sources/Services/SessionManager.swift`

---

### 14、软件版本号

显示位置：登录页标签、首页底部、我的页面「关于」区块。

- 显示格式：`v1.0.0 (1)`（`CFBundleShortVersionString` + `CFBundleVersion`）
- 版本号在 `ios/project.yml` 里配置：`MARKETING_VERSION` / `CURRENT_PROJECT_VERSION`
- 服务端可下发「最低版本号」和「最新版本号」：
  - 低于最低版本 → 打开 App 弹窗强制提醒
  - 低于最新版本 → 我的页面显示「发现新版本，去下载」
- 代码：`ios/Sources/Core/AppInfo.swift`、`Models/AccountModels.swift` → `ServerMeta`

### 15、可以走服务器

自带完整服务端（`server/`）：

| 能力 | 说明 |
| --- | --- |
| 账号 | 注册、登录、JWT、改密码、禁用 |
| 情侣 | 创建空间、邀请码、绑定、解绑、纪念日 |
| 同步 | 火花 / 宠物 / 签到 / 愿望 / 加班记录 / 设置，LWW 冲突策略 |
| 聊天 | REST 历史 + WebSocket 实时 + 已读 + 输入中 |
| 表情包 | 建包、base64 上传（校验 magic bytes）、二进制下发、删除 |
| AI | DeepSeek 代理（Key 只在服务器）、每日限额、月报 |
| 后台 | 网页管理：填 Key、开关、统计、用户管理、操作日志 |
| 版本 | `/api/meta` 下发版本与公告 |

接口契约见 `docs/API.md`，部署见 `docs/03-服务器部署.md`。
