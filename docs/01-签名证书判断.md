# 01 · 先判断你的签名证书能不能用「完整版」

这一节只解决一个问题：**我该装完整版 IPA 还是轻量版 IPA？**

- **完整版**（`CoupleApp-unsigned.ipa`）：App + 灵动岛小组件扩展，能真正上岛。
- **轻量版**（`CoupleAppLite-unsigned.ipa`）：只有一个 App，没有扩展。功能完全一样，只是灵动岛变成首页的一张卡片。

---

## 一、先搞清楚你手上有什么

| 你有的东西 | 说明 |
| --- | --- |
| `.p12` 文件 + 密码 | 证书本体。可以是①你自己 Apple 开发者账号的证书 ②淘宝/闲鱼买的「个人证书」③签名平台发的共享证书 |
| `.mobileprovision` 文件 | 「描述文件」。**有没有这个文件，决定你能不能装完整版**（下面详述） |
| 只有一个 `.p12` | 说明你的签名工具会去用 Apple ID 帮你自动申请描述文件（Sideloadly、AltStore 就是这种） |

对照下表找到自己的情况：

| # | 你的情况 | 建议装的版本 | 原因 |
| --- | --- | --- | --- |
| A | 有 `.p12` + `.mobileprovision`，描述文件里的 App ID 是**通配符**（看到 `TEAM ID.*` 或 `*`） | 先试**完整版**，装不上换轻量版 | 通配符能同时覆盖 App 和扩展两个 Bundle ID，多数情况能装上 |
| B | 有 `.p12` + `.mobileprovision`，描述文件是**显式 App ID**（例如 `ABCDE12345.com.coupleapp.ios`） | **轻量版** | 一份描述文件只能匹配一个 App ID，扩展的 `com.coupleapp.ios.widget` 匹配不上，安装会失败 |
| C | 有 `.p12` + **两份**描述文件（App 一份、扩展一份） | **完整版** | 这是最完整的签名链，工具支持分别指定就能上岛 |
| D | 只有 `.p12`，靠 Apple ID 自动申请（Sideloadly / AltStore） | **轻量版** | 免费 Apple ID 一周只能注册 10 个 App ID、最多 3 个 App，加扩展很容易超限失败 |
| E | 买的共享证书，卖家给了 p12 + 描述文件 | 看描述文件类型，同上；**并且要确认你的设备 UDID 在描述文件里** | 共享证书的设备白名单是卖家加的，没加你的 UDID 就装不上 |
| F | 完全不知道 p12 是哪来的 | 先装**轻量版** | 轻量版对证书要求最低，最容易装上；装成功后想上岛再折腾完整版 |

> ✅ 一句话结论：**不确定就先装轻量版**。装上了随时可以换完整版，App 里的数据都在服务器/本机，不会丢。

## 二、怎么判断描述文件是「通配符」还是「显式 App ID」

### 方法 1：在 iPhone 上直接看（最简单）

1. 把 `.mobileprovision` 通过微信/AirDrop 发到手机，用「文件」App 打开
2. 或者用「ESign / 全能签」里的「描述文件管理」查看
3. 找 `application-identifier` 或「应用标识」这一行：
   - `ABCDE12345.*` → **通配符**（能试完整版）
   - `ABCDE12345.com.coupleapp.ios` → **显式**（用轻量版）
4. 同时看 **ProvisionedDevices / 设备列表**：里面有你的 iPhone UDID 吗？（设置 → 通用 → 关于本机 → 长按「序列号」可复制 UDID 的一部分；或用爱思助手看）

### 方法 2：在电脑上看

`.mobileprovision` 是签名的 plist。Windows 上可以直接用记事本打开，往下翻能看到明文片段（`<key>Name</key>`、`<key>ProvisionedDevices</key>`、`<key>application-identifier</key>`）。搜 `application-identifier` 和 `ProvisionedDevices` 即可。

更省事的办法：直接用**爱思助手 → 工具箱 → IPA 签名**，导入证书和描述文件后，它会显示证书名称、有效期、支持的 App ID。

### 有效期也要看一眼

| 证书类型 | 有效期 | 到期后 |
| --- | --- | --- |
| 免费 Apple ID | **7 天** | 每 7 天重签一次，App 数据保留（不要卸载，直接覆盖安装） |
| 个人开发者（$99） | **1 年** | 重新签名覆盖安装 |
| 企业/共享证书 | 卖家说了算，常被吊销 | 换新证书重签，或换成自己的 Apple ID |

## 三、三种最常用的签名安装方式

### 方式 A：Windows + 爱思助手（适合有 p12 + 描述文件）

1. 电脑装 **爱思助手（i4Tools）**，数据线连上 iPhone 并信任电脑
2. 工具箱 → **IPA 签名**
3. 添加 IPA（完整版或轻量版）
4. 添加证书：选择 `.p12`，输入 p12 密码
5. 选择描述文件：`.mobileprovision`
6. 点「开始签名」，成功后回到「应用游戏」→ 安装到设备
7. iPhone 上：设置 → 通用 → VPN与设备管理 → 信任对应证书

### 方式 B：手机上用 ESign / 全能签 / GBox（没有电脑也行）

1. 先在手机上装好签名工具本体（这类工具本身也需要签名/企业证书，安装方式按工具说明做）
2. 工具里「证书管理」→ 导入 `.p12`（输密码）+ `.mobileprovision`
3. 「导入 IPA」→ 选择下载好的 IPA 文件
4. 「签名」→ 选刚导入的证书 → 安装
5. 设置 → 通用 → VPN与设备管理 → 信任

### 方式 C：Sideloadly（适合只有 Apple ID 或只有 p12）

1. 官网下载安装 [Sideloadly](https://sideloadly.io/)
2. 拖入 IPA
3. 填 Apple ID 密码（免费账号，7 天有效期）或选择自定义证书
4. 点 Start，按提示输入验证码
5. 装完后手机设置里信任证书

> ⚠️ 免费 Apple ID 签名 **不支持带扩展的完整版**（一周 10 个 App ID 的限制很容易被扩展用掉），请用轻量版。

## 四、安装失败对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `The executable was signed with invalid entitlements` | 扩展的 Bundle ID 和描述文件对不上（情况 B） | 换**轻量版** IPA |
| `This app was not signed` / `无法安装` | 没签名，或签名工具没走完流程 | 重新签名，别把未签名 IPA 直接装 |
| `Provisioning profile doesn't include the currently selected device` | 你的 UDID 不在描述文件里 | 让卖家加 UDID，或换 Apple ID 签名 |
| 安装到 90% 失败 | 证书被吊销 / 描述文件过期 | 换证书重签 |
| 图标是灰的、点开闪退 | 证书没被信任 | 设置 → 通用 → VPN与设备管理 → 信任 |
| App 打得开但一周后打不开 | 免费账号 7 天到期 | 重新签一次覆盖安装（**不要先删 App**，删了数据会没） |
| 灵动岛不显示 | 装的是轻量版，或系统设置里关了「实时活动」 | 装完整版；设置 → 情侣空间 → 打开「实时活动」 |

## 五、想稳定长期使用，推荐路线

| 目标 | 建议 |
| --- | --- |
| 只是自己两个人用，能忍 7 天重签 | 免费 Apple ID + 轻量版 + Sideloadly |
| 想上灵动岛、想省事 | 一个自己的 Apple 开发者账号（$99/年）+ 轻量版/完整版都能签；用 Xcode 或爱思助手签名，一年签一次 |
| 已经买了个人证书 | 按情况 A/B/C 选版本；同时把证书和描述文件备份好 |

> 📌 App 数据说明：**同一个 Bundle ID 覆盖安装，数据不会丢**。所以重签时千万不要先删除 App 再装。
> 唯一例外：完整版和轻量版的 Bundle ID 不同（`com.coupleapp.ios` 与 `com.coupleapp.ios.lite`），两者互相覆盖安装会被当成两个 App，本机数据（记账、密码本）不互通 —— 换版本前请先在 App 内「我的 → 导出本机数据」备份。
