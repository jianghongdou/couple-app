# 04 · 后台管理（网站后台）

服务端自带一个网页后台，用来**填写 DeepSeek API Key**、开关功能、查看统计。
地址：`https://你的域名/admin`（本地就是 `http://127.0.0.1:8787/admin`）

登录密码 = 服务器 `.env` 里的 `ADMIN_PASSWORD`。

---

## 一、填写 DeepSeek API Key（记账 AI 必须做这一步）

> App 端**不保存任何 API Key**，Key 只存在你自己的服务器上。

1. 去 https://platform.deepseek.com 注册并登录
2. 左侧 **API Keys** → **创建 API Key** → 复制（只显示一次，形如 `sk-xxxxxxxx`）
3. 给账号充值（DeepSeek 按 token 计费，一句话记账一次大约几厘钱）
4. 打开后台 `/admin` → 登录
5. 找到 **DeepSeek API Key** 输入框 → 粘贴 Key
6. 模型选择：
   - `deepseek-chat` —— 推荐，快且便宜，记账足够
   - `deepseek-reasoner` —— 更聪明但更慢更贵
7. 打开 **启用 AI** 开关
8. 点 **保存**
9. 点旁边的 **测试** 按钮，输入「午饭25，打车18.5」，能返回两条账目就说明配置成功

配置好之后，App 里：账本 → 「用一句话记账」就能用了。
如果没配置，App 会自动退回到**本地规则识别**（离线也能记账，只是复杂句子识别率低一些）。

## 二、后台各项设置说明

| 设置项 | 作用 |
| --- | --- |
| DeepSeek API Key | AI 记账和 AI 月报用的密钥，只存服务器 |
| DeepSeek Base URL | 默认 `https://api.deepseek.com`，用中转服务时改这里 |
| DeepSeek 模型 | `deepseek-chat` / `deepseek-reasoner`，也可手填 |
| 启用 AI | 关掉后 App 会退回本地规则解析 |
| AI 每日限额 | 每个账号每天最多调用多少次，防止 Key 被刷爆 |
| 开放注册 | 关掉后新用户不能注册（两个人的 App 建议注册完就关掉） |
| 服务器公告 | App「我的 → 关于」里会显示这条文字 |
| 最低版本号 | 小于这个构建号的 App 打开时会弹「需要更新」提示 |
| 最新版本号 | 大于当前构建号时，App 里会显示「发现新版本」 |
| 更新地址 | 「发现新版本」按钮跳转的下载地址 |
| 表情包上限 | 每个情侣空间最多能建多少个表情包 |

> ⚠️ 版本号指的是 **构建号（CFBundleVersion）**，不是 `1.0.0` 这种版本字符串。
> 默认都是 1；如果你改了 `ios/project.yml` 里的 `CURRENT_PROJECT_VERSION`，这里的门槛值也要一起改。

## 三、统计与用户管理

- **统计卡片**：用户数、情侣数、消息数、今日 AI 调用次数、磁盘占用
- **用户列表**：搜索、重置密码、禁用/启用、删除账号
- **操作日志**：记录后台每一次修改（改了什么、什么时候）

### 常用运维操作

| 想做什么 | 怎么做 |
| --- | --- |
| 对方忘记密码 | 后台 → 用户列表 → 重置密码，把新密码告诉他 |
| 有人乱注册 | 关掉「开放注册」，再删掉多余账号 |
| 不想再花钱调 AI | 关掉「启用 AI」（App 自动用本地规则） |
| 换 DeepSeek Key | 直接粘贴新的，保存即可 |
| 看两个人有没有在聊天 | 统计里的消息数会增长 |

## 四、安全建议

1. `ADMIN_PASSWORD` 用强密码，别用 `123456`
2. `JWT_SECRET` 用 `openssl rand -hex 32` 生成的随机串，**不要**泄露
3. 后台只走 HTTPS 访问，不要把 8787 端口直接暴露公网
4. 两个人用的话，注册完就**关闭开放注册**，避免陌生人占用
5. 定期备份 `server/data/` 目录
6. 后台没有「找回密码」功能，密码忘了只能改 `.env` 里的 `ADMIN_PASSWORD` 然后重启服务

> ⚠️ **换了 `JWT_SECRET` 会怎样？**
> 所有人需要重新登录（旧 token 失效），并且**后台里保存的 DeepSeek API Key 会解不开**
> —— 那时 AI 记账会报错，重新在后台粘贴一次 Key 保存即可。所以 `JWT_SECRET` 定了就别随便改。

> ⚠️ **`.env.example` 里的 `JWT_SECRET` 和 `ADMIN_PASSWORD` 是故意留空的**：
> 不填服务会直接拒绝启动并打印中文提示，避免有人拿着示例里的弱密钥直接上线。

## 五、后台打不开怎么办

| 现象 | 排查 |
| --- | --- |
| 404 | 访问路径要是 `/admin`（不是 `/admin/`），确认服务已启动 |
| 一直转圈 | 反向代理没配对，先直连 `http://IP:8787/admin` 试试 |
| 登录失败 | 密码就是 `.env` 里的 `ADMIN_PASSWORD`，改完要重启服务 |
| 保存后 App 里没生效 | App「我的 → AI 记账 → 刷新状态」，或退出重进 |
| 测试按钮报错 | 检查 Key 是否复制完整（`sk-` 开头）、账号是否欠费、服务器能不能访问 `api.deepseek.com` |
